# obsidian-agent-memory-server

一个基于 Obsidian 文档库的 Agentic Memory Server 起始仓库。

## 项目目标

- 让不同 Agent 角色在跨项目工作中持续积累可复用经验
- 在项目间实现记忆隔离与可控共享
- 兼容不同项目中的 Agent 工作流

## 当前范围（v0）

- 定义最小可行的记忆模型
- 定义角色与权限边界
- 提供基础写入与检索能力
- 建立工作流兼容层的接口约定

## 文档

- 架构占位文档：`docs/architecture.md`
- 研究记忆文档：`docs/research-memory.md`
- Agent 研究约束：`AGENTS.md`

## 里程碑（草案）

- M0：项目初始化与文档基线
- M1：最小记忆读写能力
- M2：角色化记忆与跨项目策略
- M3：多工作流适配验证
